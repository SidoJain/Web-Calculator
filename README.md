# Calculator

**Web Calculator** is a fully functional, classic calculator web application built using HTML, CSS, and JavaScript. It supports basic arithmetic operations, constants, and an intuitive user interface.

## Features

- Basic Arithmetic Operations: Supports addition (+), subtraction (-), multiplication (x), division (÷), exponentiation (^), and percentage (%).
- Constants: Includes mathematical constants π (Pi) and e (Euler's number).
- Clear and Delete Functions: 'AC' (All Clear) to clear the entire input and 'DEL' to delete the last character or operation.
- Parentheses Support: Allows for grouping operations using parentheses ( and ).
- Decimal Support: Handles decimal numbers.
- Input Validation: Basic handling of operator spacing and constant placement.
- Precision: Results are displayed with a precision of 4 significant figures.
- Responsive Design: Styled with CSS for a clean and functional appearance.

## Getting Started

### Installation

1. Clone the repository:

```bash
git clone https://github.com/SidoJain/Web-Calculator.git
cd Web-Calculator
```

2. Download the files:
If not using Git, simply download the index.html, style.css, and script.js files into a single directory.

### Running the Application

To run the calculator, simply open the index.html file in any modern web browser.

## Usage

Usage
- Click on the number buttons to input digits.
- Use the operator buttons (+, -, x, ÷, ^, %) for calculations.
- Press AC to clear the entire input.
- Press DEL to remove the last character or operation.
- Use π and e buttons for their respective constant values.
- Use ( and ) for defining the order of operations.
- Press = to see the result of your calculation.
